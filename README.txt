Abhinav Shankar H - personal site (offline copy)

Open index.html in any web browser. Everything it needs is in this folder:
  index.html     page content
  css/style.css  styles, including the local font definitions
  js/main.js     animated constellation and the "Copy email" button
  fonts/         the three typefaces as .woff2 files

Keep the folder structure as it is; index.html looks for css/, js/ and fonts/ next to it.
External links (LinkedIn, GitHub, IEEE papers) still need an internet connection.
