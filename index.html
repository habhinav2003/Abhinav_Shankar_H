Selected work
Ericsson Canada2026 – now

Automated defect diagnosis for radio test dashboards

The second stage of a two-stage radio QA system. When a capture from a spectrum-analyzer dashboard is flagged, the pipeline diagnoses which of 11 defect types it shows, from high EVM and phase error to early or late switching and spectrum roll-off. Each defect is checked only on the panels an RF engineer would look at.

Failure analysis on uplink and downlink captures showed the high-EVM misses were a threshold-calibration problem rather than domain shift. I also built the tools engineers use around the models: a Streamlit app for running the pipeline and a browser review tool that syncs manual labels with model predictions.

  • 11 defect classes
  • 789 UL/DL captures analysed
  • AUC 0.97 on high EVM
  • YOLO · SAM2 · HDBSCAN · Random Forest
